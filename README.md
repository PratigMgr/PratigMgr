### ♿ Accessibility Compliance Dashboard
A full-stack operational tool where each scan moves through validated states (queued, scanning, completed, failed), backed by a REST API and a MongoDB schema/query layer kept cleanly separate from business logic. Automated with Playwright end-to-end checks and axe-core accessibility scans, plus server-side filtering, sorting, and pagination over historical scan results. Containerized with Docker for consistent local dev and deployment.

### 🤖 AI Code Review Agent
A GitHub PR review agent that grounds feedback in a repo's own code, retrieving similar existing code via a self-built JSON vector store before generating review comments. Automates a manual PR-review process end-to-end via webhooks (GitHub/Octokit) and Groq's LLM, with a labeled eval harness (planted-bug test cases plus an automated grader) to catch regressions. Combines Groq's free-tier LLM with local transformers.js embeddings, deployed as a single Render service with no external database.

### 🖥️ Contact Manager — Desktop App
A C#/.NET (WPF) desktop application architected around a repository-pattern data-access layer (IContactRepository over ADO.NET/SQL Server), cleanly separating UI, business logic, and data access. Implements regex-based input validation with custom exceptions surfaced to the UI, catching invalid data before it reaches the database.
